### 🔹 **Desafios sobre Variáveis**

#### **Desafio 1: Conversão de Temperatura**
Crie um programa em Kotlin que recebe uma temperatura em graus Celsius e a converte para Fahrenheit. Use uma variável para armazenar a temperatura e outra para armazenar o resultado. A fórmula de conversão é:

\[
F = (C \times \frac{9}{5}) + 32
\]

📌 **Exemplo de entrada:**
```kotlin
val temperaturaCelsius = 25
```  
📌 **Saída esperada:**
```kotlin
Temperatura em Fahrenheit: 77.0
```

#### **Desafio 2: Cálculo do IMC**
Crie um programa que recebe o peso (em kg) e a altura (em metros) de uma pessoa e calcula o Índice de Massa Corporal (IMC). A fórmula do IMC é:

\[
IMC = \frac{peso}{altura^2}
\]

📌 **Exemplo de entrada:**
```kotlin
val peso = 70.0
val altura = 1.75
```  
📌 **Saída esperada:**
```kotlin
Seu IMC é: 22.86
```
